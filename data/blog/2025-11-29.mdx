  担忧的是解锁有失败以及有三处标记为服务器
  - 通过与 Claude Opus 4.5 交流，一般分析 IP 质量与风险还有
    1. 历史滥用记录 — 该 IP 或所属 IP 段是否有过垃圾邮件、爬虫、攻击等行为
    2. ASN 整体信誉 — 某些运营商的 IP 段整体信誉较差
    3. IP 共享程度 — CGNAT 下大量用户共享同一 IP，容易被连坐
    4. 地理位置异常 — IP 归属地与访问行为不一致
    5. 黑名单数据库 — 是否被 Spamhaus、AbuseIPDB 等收录
    6. 主流 IP 情报厂商

       第一梯队:
       - MaxMind — 老牌厂商，运营超过 20 年，开发了 MMDB 数据库格式，是行业标准
       - IPinfo — 后起之秀，根据网站使用量统计，IPinfo 比 MaxMind 流行约 1.8 倍

       第二梯队:
       - IP2Location（2002 年成立）
       - ipdata
       - IPQualityScore（专注欺诈检测）

       MaxMind 是老牌标准，IPinfo 是当前最流行的选择，ipdata 相对小众
  - 与 Claude 讨论后，分出的结论是 BageVM 是"双 ISP + 零黑名单 + Scamalytics 0 分"的组合，属于高质量住宅 IP；ZgoCloud 虽然大部分指标也不错，但单 ISP + 有黑名单记录 + 部分流媒体屏蔽，说明已经有一定的"污染"。
  - 所以 主力落地 IP 应该是使用 BageVM，ZgoCloud 在 12月初到期后应该就是不再续了，还在考虑中
  - 但是在 ios safari private 访问 google 还是会被 RECAPTCHA，一种说法是 APPLE 激进的隐私策略尽可能的抹除了真人特征，一种说法是 IP 质量还是不够
    1. 做了简单测试，在 ios safari private 模式下先用 手指 滑动停留几秒再访问 google 就不会出现 RECAPTCHA
    2. 记得以前体验号称[家宽IP](https://voyracloud.com/)时，在 ios safari private 访问 google 没有出现 RECAPTCHA
    3. 所以对落地 IP 质量还是有担忧，但碍于成本，综合下来 BageVM 目前时更合适的
