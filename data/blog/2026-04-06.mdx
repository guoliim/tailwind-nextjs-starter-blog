原本说想一个月写一个记录的，但是一个是还没习惯，一个是还是有点手懒，所以就拖到了一个季度来写一下了。

第一个月其实在工作上没有什么大的变化，但是又被母上介绍了几个相亲的对象，有个是大专的老师，沟通起来非常的流畅，给人一种一周就好确定下来关系的感觉。而且女生相对来说也比较主动，沟通起来也非常顺滑，但是还是出问题了。我在认识之前就给母上说了，肯定不会买新房的，都是默认这个前提开始认识的。这位老师最后还是说出来要买房说是看态度，没有意义，我说出了相对来说比较狠的话那就是「这样，不适合过日子」就结束了，现在想起来，我觉适合一起玩，不适合做长期的伴侣，因为给人一种长不大，还是在做公主梦的阶段。

还有一个是一位大学老师，就比我小一岁，年龄其实也不小了，同时在短短续续的沟通中，但是在与大专老师频繁交流过程中，中间大概有一个多礼拜没有联系过了。由于预感到会与大专老师崩掉，所以在断联之后，又沟通起来了。

一月份的时候 还有同学从外国回来了2天大概。第一天晚上在一起吃饭，第二天就是为了跟大专老师第二次 date 就没去了，反而估计一年都见不到了，有点不应该。

还有另外一个以前的同学，说是，有没有可能性一起合作一个项目，确实没有经验就问了问同事，搞，后面被彻底打脸，疼的很。

二月份的时候，跟大学老师见了两面，第一面觉得还行，但是第二面却造成了灾难。大学老师说，第二次见面过程中，没有互动，没有看她，没有讨论电影内容。看完后晚上十点多了，去完卫生间没有等她，出来以后不知道要去哪里，由于处在过年阶段，确实没有其他地方去。大学老师其实家境比我好的非常多，好像那晚还说去酒吧或者SPA之类的，我都露怯了没搭话，就各自回家了，也没送她回去，她表示体感非常差，不太想再接触了，这么说了以后，我才发现问题在哪里，我还想着再约见面，却一直再也没见到了。而且这次灾难后，我发现我好像真的在意这位大学老师了，就称作王老师吧。一开始想在过年期间再见一次，但王老师是不想见。搞的我没招，还有点患得患失，逼得我没办法和AI讨论如何解决这个问题，如何有计划的同王老师聊天，挽回灾难。

三月份的时候，一个是 code agent 在公众号的发现与传播焦虑，我们这个部门领导直接说不再找传统开发了。而且产品在用了 code agent 之后一直再说能取代前端了。原则上来说确实还没完全到，但是确实也快了。而且我到四月就在这个单位第一份合同到期了，要面临续签的问题，而且还搞了一个新花样，就是要答辩。答辩啥啊，不续签就给赔偿被，搞这种形式主义干嘛呢，又不是说名义上答辩不通过就不用给赔偿了。反正PPT，已经准备好了，我觉得没啥意义。

同学是他们的单位的中层领导了，有一个大项目，不过是关于工业软件方向的，说白了就是找外包厂商，我想着这是机会啊，就又问了一个产品的领导能不能介绍进来，说是可以啊，签下来就是我们的业绩了，可以聊。然后我跟我同学反馈了，我还憧憬着，有了这个事情终于不用再做大头兵，不用这么焦虑了。就联系了我们部门最大的领导，领导的意见是不是我们的方向，不用浪费时间。我说这是我同学的关系看看有没有合作，领导没有继续说不做了，又问对方是什么来头，我也大概介绍了，线上会议的上午我还再次确认了，可以聊一聊，还说准备找工业软件方向的不同部门的同事来，还有AI方向的人来。可是线上就坏了，我同学说了一个大概后，直接说做不了，然后结束了。我就感觉我被耍了，但是我还得安抚我的同学，让他别介意，但是我肯定已经被质疑了，唉，这领导也是有意思，要不就不要线上沟通，要不就是会后再说做不了，直接说不做，太难看了，毁的是我，以及我与我同学之间的关系。难受的不得了。

我还想着这不要续签了么，介绍项目给院里，我肯定是能续的，这下这些都不想了，爱怎么样就怎么样吧。但是我还是在做梦想着，是不是有机会能把这关系项目包一点下来自己做，但是问题是需要满5个人半年社保的公司，这太难搞了，成本太高我没搞，其实项目合作的事情，陆陆续续有聊过一年，一开始都没当真，但是就年前，认真讨论起来了。主要是还是自己经验不足，希望以后还能有机会。我还在想，要是真的被裁了，就联系一下同学，看能不能做个现有承包商的产品或者项目经理，吃同学的项目，先混着再说。

3月份的时候，王老师说是要赶青年基金和面上项目。提过一次见面，头天都已经答应了，但是到当天，下午问了没有回，7/8点的时候说是通宵了。唉，那怎么办忍了呗。没法办现在我处于主动方，要承担这个不平衡感。后面就隔个一两天主动问一下，聊几句。然后 从3月中旬说是能交稿一直到现在都没交掉。月底的时候交了一次，说是要休息整个周末，我就没找她了，后来又说我为啥没约她，这能怪我么。说完我没约她后，我就下周约，又说还有省的本子要交，一开始说是月底就交的掉，现在又说不行，要到4月9日才行。但是中间又说跟以前同事去吃饭，唉我也在同一个城市，为啥我就不能行呢。唉，等等吧。不过确实成本太高了，整整快2个月没见到过了。4月12号是她生日，我还在挑礼物，日式花器，希望能见到，能送给她，能有意义吧。

我妈又介绍了一个新的女生，是一个幼儿园老师，不给照片，见了一面，除了像男生以外，观感上还可以的，不过估计也没看上我，那天没吃饭，到家了，也没告诉我到家了，我还是被迫问了一下，感觉怎么样，说的也是片汤话，算了我就没在联系了。

我自己在年后在看 CODE AGENT / HARNESS ENGINEERING 的东西，从头或者半路训练 LLM，我连显卡成本都负担不起，不合适我，只能泛泛了解一下。但是 AGENT 确实可以投入一下，我觉得是值得的。
